# OCR 比較用テスト文書

OCR エンジン（OSS と Claude）を同じ条件で比べるための、自作のテスト文書です。
すべて架空の内容なので、外部のサービスに送っても問題ありません。

## 文書の一覧

| ファイル | 内容 | 確かめたいこと |
|---|---|---|
| `01_oshirase` | お知らせ文 | 普通の文章の読み取り精度（基準） |
| `02_seikyusho` | 請求書 | 数字・金額・記号（¥ ％ 〒 ×）の正確さ、左右に並んだ欄の読む順番 |
| `03_jikanwari` | 時間割の表（A4 横） | 表の読む順番、`—` や `–` などの紛らわしい記号 |
| `04_chirashi` | チラシ | 2 段組みの読む順番、大小の混ざった文字、丸数字 |
| `05_shiyosho` | 製品の仕様書 | 小さい文字（7.5pt）、英数字と単位（μs ± ° ≦ × ℃ −） |

### 英語版（`en/`）

本番で読むのは海外の文書（英語）なので、同じ 5 種類を英語で作り直したものが `en/` にある。
海外の書類として自然な形にしている（ドル建て・月/日/年の日付・売上税、Times 風／Arial 風の書体）。

| ファイル | 内容 | 確かめたいこと |
|---|---|---|
| `en/01_notice` | 避難訓練のお知らせ（Times 風の書体） | 普通の英文の読み取り精度（基準） |
| `en/02_invoice` | 請求書（ドル建て） | 金額・品番・日付（$ % × ·）、左右に並んだ欄の読む順番 |
| `en/03_schedule` | 時間割の表（A4 横） | 表の読む順番、`—`・`–`・曲がった引用符 `“ ”` |
| `en/04_flyer` | ワークショップのチラシ | 2 段組みの読む順番、`•` の箇条書き、大小の混ざった文字 |
| `en/05_datasheet` | サーボモーターのデータシート | 小さい文字（7.5pt）、単位と記号（μs ± ° ≤ × °C −） |

それぞれ次の 2 つのファイルがあります（日本語版・英語版とも）。
- `*.pdf`：印刷する紙
- `*.txt`：正解テキスト。印刷される 1 行が、テキストの 1 行に対応します。表は 1 行につき 1 行で、セルの区切りは ` | ` です。2 段組みは「左の段 → 右の段」の順です。

紙の四隅には ArUco マーカー（`DICT_4X4_50` の ID 0〜3、一辺 25mm、左上 0 から時計回り）が入っています。
これは OCR エンジンの比較用の仮の仕様です。本番の紙は下の「カード」です。

### カード版（`card/`）— 本番の紙

読む紙を小さいカードにしたので、その台紙に合わせて作った英語の文書。ROS 2 ノード `ocr_node` はこの紙を読む。

| ファイル | 内容 |
|---|---|
| `card/corner0.pdf` | 台紙（マーカーだけ）。下半分に寸法と印刷の倍率チェック用の目盛りがある |
| `card/01_notice` | 避難訓練のお知らせ（Times 風の書体） |
| `card/02_invoice` | 請求書（3 品目、小計 125.87・税 8.25% 10.38・合計 $136.25） |
| `card/03_flyer` | ロボット講座のチラシ（枠囲み・箇条書き） |
| `card/sim_02_invoice.jpg` | `02_invoice` を斜めに置いて D435i くらいの画質にした**合成画像**（カメラなしで試す用） |

台紙の仕様:
- A4 の上半分（210 × 148.5 mm）を切り取って使う。**台紙の右端が、読むときの上**（読む向きでは A5 縦）
- ArUco `DICT_4X4_50` の **ID 1〜4**。台紙の向きで左上 1・右上 2・右下 3・左下 4（読む向きでは左上から時計回りに 2, 3, 4, 1）
- 黒い四角は一辺 **30mm**、紙の端から 15.5mm（白い余白 7.5mm を含めると 8mm）

文字は読む向きで書き、台紙の真ん中（読む向きで上から 56〜154mm）だけに置いて、マーカーとその周りの白い余白を避けている。
作り直すときは `make_cards.py` の `CARDS` を書き換えて実行する（`make_docs.py` と同じ環境に `pypdf` を足す）。

```bash
.venv/bin/pip install weasyprint pypdf
.venv/bin/python make_cards.py
```

印刷は **A4・等倍（拡大縮小なし）**。台紙の下半分にある 100mm の目盛りが、ちょうど 100mm になっているか定規で確かめてから切る。
画面で粗く表示すると、マーカーの中に細い白い線が見えることがある（小さな四角の集まりで描かれているため）。印刷では出ない。

## 印刷と撮影

1. PDF を **A4・等倍（拡大縮小なし）** で印刷します。`03_jikanwari`・`en/03_schedule` は横向きです。
2. 1 枚につき 2 通り撮影して、日本語版は `photos/`、英語版は `en/photos/` に入れます。

| 撮り方 | ファイル名の例 | 想定している状況 |
|---|---|---|
| 真上からまっすぐ | `01_flat.jpg` | ArUco で正対補正したあと |
| 斜めから（影が少しあってもよい） | `01_angle.jpg` | アームのカメラでそのまま撮った状態 |

ファイル名の先頭の番号は、文書の番号（01〜05）に合わせてください。

## 作り直すとき

`make_docs.py` を実行すると、PDF と正解テキストが同じデータから作り直されます（内容を変えたいときもこのファイルを編集します）。

```bash
python3 -m venv .venv && .venv/bin/pip install weasyprint
.venv/bin/python make_docs.py        # 日本語版
.venv/bin/python make_docs.py en     # 英語版（en/ に出力）
```
